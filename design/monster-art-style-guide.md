# 「微光防线」怪物美术风格指南

> 参考图：[style-reference-sheet.jpg](enemy-candidates/style-reference-sheet.jpg)（历史概念稿，正面 / 侧面 / 背面三视图）
>
> 用途：给任何图像模型或程序化绘制 Agent 使用，生成与现有怪物统一风格的新怪物。

---

## 1. 一句话风格定义

**低分辨率、圆润 Q 版、厚黑描边的 16-bit 风格像素生物。剪影一眼可读，配色压低饱和度，但每只怪身上有一个暖色或发光的“记忆点”。从自然生物出发，加入一个和所在区域相关的奇幻或机械元素。**

英文关键词（可直接给模型）：
`chibi pixel art creature, 16-bit SNES style, 64x64 sprite, thick dark outline, chunky readable silhouette, muted earthy palette with one warm accent, 3-4 tone cel shading, top-left light, soft oval ground shadow, cozy fantasy, tower defense enemy`

---

## 2. 造型规范

| 项目 | 规范 |
| :--- | :--- |
| **画布** | 64 × 64 px。怪物主体约占 60–75%，底部留出投影位置 |
| **比例** | Q 版矮胖：头身比约 1 : 1 到 1 : 1.5，身体宽于高，四肢短小或藏在身体下 |
| **剪影** | 缩到 16 px 也能认出来。只用一个夸张特征表达身份：大钳、蜗壳、矿灯帽、年轮树桩、蝎尾、晶核 |
| **几何** | 主体由圆、椭圆、圆角块组成；尖锐元素（冰晶、刺、钳）只作点缀 |
| **朝向** | 必须提供 **正面 / 侧面（朝右）/ 背面** 三视图，三者体型、配色、特征位置一致 |
| **背面** | 不画眼睛和脸，改为露出背部特征（背甲纹、壳纹、背包、尾巴、背晶） |
| **姿态** | 静止也带动势：重心略前倾、低伏或抬尾，体现玩法定位（快怪伏地、肉盾敦实、Boss 悬浮） |

---

## 3. 像素与描边规范

- **描边**：1 px 的连续深色外轮廓，用该怪主色的最暗色（深褐、深墨蓝、深紫），**不用纯黑 #000**。
- **内线**：仅在结构分界处用一档深色内线（壳纹、年轮、甲片），保持少而清晰。
- **明暗**：每种材质 3–4 阶色（暗部 / 中间色 / 亮面 / 高光），硬边分块着色，**不做渐变和抖动噪点**。
- **光源**：统一来自**左上方**，左上边缘有 1 px 亮边，右下偏暗。
- **高光**：小块方形高光点（1–2 px），放在眼睛、甲壳、金属、晶体上。
- **投影**：脚下一个扁椭圆深色阴影，半透明，与身体分开；悬浮怪的阴影离身体较远。
- **抗锯齿**：不使用自动抗锯齿，边缘保持清楚的像素阶梯。

---

## 4. 眼睛与表情（生物感 + 敌对感）

- 眼睛是**最亮的点**：小黑豆眼加 1 px 白色高光，或亮色发光眼（琥珀、红、青）。
- 敌对感靠细节表达，**不做血腥或恐怖**：
  - 斜压的眉骨、半眯眼
  - 微露的小獠牙、钩喙、利爪、钳子
  - 发光的危险部位（尾晶、炉渣、晶核、矿灯）
- 整体仍保持“可爱但不好惹”的 cozy fantasy 调性。

---

## 5. 区域配色体系

每个区域有一套背景色和怪物主色，怪物需在对应背景上清晰可读。每只怪限 **主色 1 + 辅色 1 + 记忆点强调色 1**（外加描边与高光）。

| 区域 | 场景背景 | 怪物主色倾向 | 强调色（记忆点） | 主题元素 | 示例怪物 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 林缘岗哨（01–03） | 墨绿森林、松树剪影 | 橙棕毛皮、木褐 | 苔绿、松针绿 | 动物 + 植物共生 | 松针跳鼠、年轮树灵 |
| 苔岸河湾（04–05） | 青绿水岸、芦苇 | 墨青甲壳、铜棕螺壳 | 橙红大钳、嫩芽黄 | 水生甲壳 + 水草 | 苇哨蟹、渡灯蜗 |
| 弃采矿道（07–09） | 赭褐岩土、斜向矿脉 | 土棕、铁锈橙、煤灰 | 矿灯黄、炉渣橙红 | 生物 + 采矿装备 | 矿灯鼹、炉渣矿车 |
| 霜脊高地（10–12） | 灰蓝雪原、白色冰锥 | 雪白、灰蓝、石板蓝 | 冰青晶体、琥珀喙/眼 | 极地动物 + 冰晶 | 冰帆貂、霜铃鸮 |
| 裂谷深处（13–15） | 暗紫岩壁、紫晶簇 | 暗紫、葡萄紫、玄岩灰 | 品红 / 亮紫发光晶体 | 节肢 / 构造体 + 晶体 | 待设计 |

> 跨区域禁止混用：前序区域的配色主题和怪物不能直接出现在后续区域。

---

## 6. 设计公式（生成新怪时套用）

```
新怪物 = [区域本土生物原型] + [一个区域奇幻/机械元素] + [一个与玩法对应的夸张部位] + [一个发光或暖色记忆点]
```

| 玩法定位 | 体型与造型提示 |
| :--- | :--- |
| 轻型快怪 | 小体型、低伏、流线型、长耳或长尾，侧面呈前冲姿势 |
| 慢速肉盾 | 宽大方墩、短腿、厚壳或木质 / 岩质外皮 |
| 一次护盾 | 带可见外壳或护盾结构，破盾后能明显看出变化 |
| 小队支援 | 带乐器、铃铛、旗、灯等“发号施令”的道具 |
| 短距冲刺 | 有冲刺部件（钻头、鼻、角），配蓄力时的发光状态 |
| 重型装甲 | 机械或矿物外壳、铆钉、金属板，颜色更沉 |
| 突进精英 | 比普通怪大约 1.3 倍，带危险发光部位（尾晶、刃） |
| Boss | 对称或悬浮构图，中央核心发光，周围有环绕护石或护甲；开合两态 |

---

## 7. 动画规范（程序化实现参考）

- 每个朝向 **4 帧**循环：`[接触, 腾起, 最高点/伸展, 回落]`。
- 起伏幅度：地面怪 0.5–3.5 px，飞行怪 1–2 px 上下漂浮 + 翅膀大幅摆动。
- 技能状态单独出一组姿态（抬钳、开壳、蓄力发光、护石张开）。
- 项目内实现统一使用 `paintSprite(..., 2)`。发光、粒子类特效必须受 `highQuality()` 与 `reducedMotion` 开关控制。

---

## 8. 禁止事项

- ❌ 写实比例、细长四肢、复杂解剖结构
- ❌ 高饱和霓虹色铺满全身；同一怪物超过 3 种主色相
- ❌ 渐变、模糊、软阴影、噪点抖动、自动抗锯齿
- ❌ 纯黑描边或无描边
- ❌ 血腥、恐怖、成人化元素
- ❌ 背面画脸；三视图之间配色或特征位置不一致
- ❌ 和背景色同色系且同明度，导致在战场上看不清

## 9. 可直接使用的提示词模板

### 中文模板

```
像素风塔防怪物设计，64×64 像素，16-bit SNES 风格，Q 版矮胖比例，
1 像素深色描边（非纯黑），3–4 阶硬边色块明暗，左上光源，脚下扁椭圆投影。
区域：【霜脊高地】，背景【灰蓝雪原与白色冰锥】。
怪物：【雪原冰兔】，原型【北极野兔】+ 区域元素【背部冰晶刺】，
玩法定位【轻型快怪】：低伏前冲姿势、后掠长耳。
配色：主色【雪白/灰蓝】，辅色【石板蓝】，强调色【冰青晶体 + 琥珀红凶眼】。
敌对细节：斜压眉骨、微露獠牙、冰锋小爪；整体可爱但不好惹。
输出同一角色的正面、侧面（朝右）、背面三视图，横向排列，配色与特征保持一致，背面不画脸。
无渐变、无模糊、无抗锯齿。
```

## 10. 交付检查清单

- [ ] 64 × 64，主体占比合适，底部有投影
- [ ] 正面 / 侧面 / 背面三视图齐全且一致
- [ ] 缩小到 16–24 px 仍能凭剪影识别
- [ ] 1 px 深色描边 + 3–4 阶明暗 + 左上光源
- [ ] 一个明确的发光或暖色记忆点
- [ ] 配色符合所属区域，在区域背景上清晰可读
- [ ] 有敌对细节但不血腥，整体仍是 cozy 风格
- [ ] 造型能看出玩法定位（快怪 / 肉盾 / 支援 / Boss 等）
