# 《微光防线》v1.0.5 更新说明

## 短版（可直接粘贴到更新说明）

本次更新加入闯关制主线与解锁动画，并强化第 14–18 关挑战：

- 关卡按顺序逐步解锁，未解锁站点与地区自动隐藏；通关后探路者沿地图小径前往新站点并播放解锁动画。
- 第 14–18 关普通怪数量提升约 10%，基础怪与强化怪血量分层；毒沼小 Boss 生命与减速抗性上调。
- 系统设置新增隐私政策入口；游戏保持离线单机，无账号、无广告、无内购。
- 优化安装包体积与权限声明。

## 长版

### 新增闯关制地图

- 只显示已通关进度及下一站，未解锁关卡、地区页签和地区关卡按钮不再提前显示。
- 旧存档按最高已通关关卡保留进度。
- 清关返回地图后，新节点缩放发光出现，区域标签与页签同步入场；探路者沿真实小径走到新站点，完成后自动选中新关。

### 第 14–18 关难度调整

- 从每关第 3 波开始，普通怪数量约增加 10%，前期波次保留原有缓冲。
- 基础怪血量系数调整为 1.15，强化怪调整为 1.22，拉开普通单位与强化单位的坦度层级。
- 鞭须泥鲶、瓮背石蚌、芦影织蛛的生命值和减速抗性提高，毒沼小 Boss 不再明显弱于前区。
- 第 13、14 关三星路线仍可通过。

### 其他

- 系统设置新增“隐私政策”，点击后使用系统浏览器打开公开政策页面。
- 保持纯离线单机体验：无账号、无广告、无内购、无网络权限。
- 安装包约 16 MB。
