冷却按每只怪物的战斗时间独立计算。普通移动、近战动作和技能冷却分别计时。

新批次透明图集为 256×512 像素。列从左到右为东、南、西、北，前四行为移动帧，后四行为预备、蓄力、命中或施法、收招。落脚点沿用每格的 `(28, 54)`。使用 `python3 design/enemy-candidates/draw_regional.py src/render/enemy-art` 重绘新批图集。

霜刺豪猪的动作由游戏内的 [frost-creatures.ts](../../src/render/frost-creatures.ts) 绘制，发射前后的冰刺形态由战斗状态驱动。

## 既有候选

每只怪物绘制了正面、右侧面和背面，左侧面以右侧面镜像生成。松针跳鼠、年轮树灵、苇哨蟹、渡灯蜗、矿灯鼹、炉渣矿车和冰帆貂已在主线出场。霜铃鸮在第 12 关登场。表中编号是设计建议，实际出场以关卡波次为准。

## 素材规格

- 每张透明 PNG 为 256 × 64 像素，共四格。每格 64 × 64 像素，从左到右为东、南、西、北。
- 建议以每格左上角为原点，取 `(28, 54)` 作为落脚点，与项目现有的像素精灵对齐。预览使用最近邻缩放。
- `catalog.json` 记录素材路径、关卡建议和玩法定位。每个朝向一帧，供选型和走路动画制作。
- 源稿位于项目的 `design/enemy-candidates`。安装 Pillow 后运行 `python3 design/enemy-candidates/export_assets.py 导出目录` 可重新生成。非 macOS 环境可传入 `--sprites-only` 导出图集。
- 使用 `python3 design/enemy-candidates/export_assets.py --game-atlases src/render/enemy-art` 可生成游戏图集。带技能姿势的图集第二行依次为东、南、西、北。
